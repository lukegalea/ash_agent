# AshAgent host behaviours

**Not yet built.** No behaviour ships in this version.

When they land, this page will describe each behaviour a host implements and when the package calls it:

- who an invocation executes as;
- how an approval is opened for a row and how its decision is read;
- where the history shown in an execution explorer comes from.

The package calls these behaviours instead of reading the host's actor, tenant or grant data itself.
