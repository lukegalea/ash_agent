# AshAgent triggers

**Not yet built.** No action in this version expects a trigger.

The package ships no workers. When its actions land, this page will give the name of each ash_oban trigger the actions
expect and a template `oban` block for the host's resource: worker and scheduler module names, queue, schedule,
default actor and the read action the trigger uses. The host declares the block on its own resource and owns the
workers it generates.
